## ScalaFX-Extras Release v.0.13.0

This is a bugfix release of [ScalaFX-Extras].

### New features

* ScalaFX updated to 27.0.0-R39
* `FileSelectionField`, `DirectorySelectionField`: `ownerWindow` defaults to `None`, the chooser is then owned by
  the window containing the field [[#53]]
* Improve Scaladoc generation

### Bugs Fixes

* `GenericPane`, `GenericDialogFX`: `resetReadout()` did not reset checkbox, choice, and number fields;
  `GenericDialogFX` readout now restarts each time the dialog is shown [[#50]]
* `BatchRunnerWithProgress`: final summary could use stale counts, or fail for an empty task list [[#51]]
* `ParallelBatchRunner`: a task returning `null` was reported as canceled [[#52]]
* `FileSelectionField` [[#49]], `DirectorySelectionField` [[#48]]:
  - "Browse" failed for a bare file name, like `data.txt`
  - the selected file, instead of its directory, was remembered as the last directory
  - initial directory of the chooser could not be determined for some paths
  - paths are now as clean as possible, without `.` and `..`
  - when the directory in the path does not exist, the chooser opens in the nearest existing parent directory

### API Breaking Changes

* `DirectorySelectionField.existingOrParent` removed; it was an internal helper not intended as public API. [[#48]]
