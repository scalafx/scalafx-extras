Helper methods and classes to simplify ScalaFX use.

| Package                                        | Description                                                                                           |
|------------------------------------------------|-------------------------------------------------------------------------------------------------------|
| [[org.scalafx.extras]]                         | Running code on and off the FX application thread, running UI tasks with [[org.scalafx.extras.BusyWorker BusyWorker]], and showing message dialogs with [[org.scalafx.extras.ShowMessage ShowMessage]]. |
| [[org.scalafx.extras.auto_dialog]]             | Input dialogs created automatically from case classes.                                                |
| [[org.scalafx.extras.batch]]                   | Running batches of tasks, sequentially or in parallel, with a progress dialog.                       |
| [[org.scalafx.extras.generic_pane]]            | Input panes and dialogs built by adding fields: text, numbers, check boxes, choices, files and directories. |
| [[org.scalafx.extras.image]]                   | Image display component with scrolling, zooming, and overlays.                                        |
| [[org.scalafx.extras.mvcfx]]                   | Model-View-Controller-like pattern for UI components with views defined in FXML.                      |
| [[org.scalafx.extras.progress_dialog]]         | Dialog showing progress and status of a long-running operation.                                       |
